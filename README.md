## 치트·편의 기능

| 조작 | 기능 |
|---|---|
| 필드에서 SELECT+START | 치트 메뉴 열기 |
| 메뉴에서 ↑↓ / ←→ / B | 항목 이동 / 값 변경 / 닫기 |
| START+A | 살아 있는 주인공 HP·MP 회복 |
| START+X | 활성 적대 대상의 HP를 1로 낮춤. 주인공·아군·죽은 적은 제외 |

| 치트 항목 | 선택값·효과 |
|---|---|
| 공격력 / 방어력 / 경험치 / 자원배수 | 각각 1·3·5·10·20·30배, 끝값 순환 |
| 무적 | 끔/켬 |
| 자원배수 적용 대상 | 영기·선단·방/통로 건설 포인트 등의 획득 경로. 소비량을 곱하는 기능은 아님 |

치트 메뉴가 열린 동안 게임 타이머가 정지하며 닫으면 다시 진행합니다. 설정은 확장 SRAM에 보관됩니다. 메뉴는 일반 필드에서 사용하며 스승전 등 별도 스크립트 전투 문맥은 지원 완료 상태가 아닙니다. 자원배수는 구현에 연결되어 있지만 실제 자원 지급의 배율 검수는 아직 남아 있습니다. START+X는 HP를 0으로 지우지 않아 원래 처치·보상 절차를 유지합니다.
